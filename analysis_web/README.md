# 水热液化分析前端

新增预测与鲁棒性入口：`pipeline.html`。使用现有 121 个原生工况的冻结分割，新增 3 点 Aspen 复核，提供 4,941 个 GP 预测网格及 266 个候选工况的 1,024 组扰动分析。比较能耗、碳足迹、单体产出的波动和排名稳定性，不设工况达标门槛。网页可下载原生扫描计划，本地 Windows/Aspen 执行；原始 `study.json` 保留。计算边界、误差、警告与复现方法见 [HTL pipeline](../htl_pipeline/README.md)。

线上英文版：https://vercel-pi-ten-59.vercel.app/index.en.html ；中文版：https://vercel-pi-ten-59.vercel.app/ 。2026-11-17 已部署并在 Ego 验证。当前通过 Vercel CLI 手动发布，GitHub 推送尚未配置自动部署。

在仓库根目录运行 `python -m http.server 8766 --bind 127.0.0.1 --directory analysis_web`，打开 `http://127.0.0.1:8766`。

首页采用研究数据工作台布局：三项主指标、可点击的温度×管长碳足迹矩阵、当前工况 STD/HR 配对条形图和紧凑研究路径。桌面使用深色侧栏与固定工况选择条，较窄屏幕切换为顶部导航；各模块保留同一组工况控件。工况与流程页从上到下为分析入口、设备选择、三维场景与参数面板；参数面板可切换“设备参数”和“STD/HR 对照”。页面采用单一文档滚动，移动端纵向排列。工作区下方可展开完整指标与热负荷。

三维场景支持拖动旋转、Ctrl/Command + 滚轮缩放、全景/俯视、设备或文字标签点选；普通滚轮滚动页面。双击设备聚焦，也可使用“聚焦设备”按钮。场景获得键盘焦点后，方向键旋转，加减键缩放，0 恢复全景，Escape 退出聚焦。STD/HR 切换同步更新设备热负荷、总等效电耗、碳足迹和回收路径。设备外形、盘管、位置和尺寸均为概念示意。金色连线表示能量回收关系，不表示新增物料流。

数据统一读取 `data/study.json`：20 个工况、40 套配对方案；来源与核算约定见 `../analysis_data/README.md`。切换工况只读取归档结果。当前数据未单独导入换热器热负荷，因此换热器面板展示 STD/HR 加热器负荷，未将其差值冒充换热器测量值。

`vendor/three.min.js` 从用户提供的 `index.html` 中原样提取，保留内嵌版权头；对应许可证见 `vendor/LICENSE-three.txt`。仅复用绘图库，场景与交互由 `plant-view.js` 实现。参考文件中的业务计算、示例指标、登录和服务端接口未引入。

本地预览检查：七类设备导航、三维物体点选、工况与方案联动、视角切换及缩放、清单与碳足迹弹窗、LCA 与工况筛选导航。330 °C / 10 m / HR 对照：电耗 14.478 kWh，GWP 62.723 kg CO₂-eq，CF 10.411 kg CO₂-eq/kg。
