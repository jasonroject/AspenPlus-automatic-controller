针对首次使用 Local Aspen models 页面的用户，以下为 4 个最易卡壳的具体交互断点及黑白极简风格的布局与中英文微文案修正：

1. 断点一：Step 1 三种入口（已有结果 vs 示例 Profile vs 本地探查 CLI）层级混淆

首次进入时，用户易被命令行（CLI）劝退，或找不到直接看结果的捷径。

布局修正：Step 1 主卡片左列放 Profile 上传与 HTL 预设按钮，右列折叠收纳只读 CLI；主卡片正下方设独立的浅灰底横幅作为“直接导入已有结果”的跳步通道。

微文案：

主入口：Upload model profile (.json) / 上传模型配置 (.json) | Load HTL reference profile / 加载 HTL 参考配置

只读 CLI 折叠区：Need a profile? Run read-only local discovery (Windows with licensed Aspen; inspects a copy without running simulation) / 需要生成配置？运行本地只读探查命令（需已授权的 Windows Aspen 环境；仅读取副本结构，不运行求解）

底部跳步横幅：Already have run outputs? Skip setup — Import combined project.json or prediction bundle → / 已有运行结果？跳过配置，直接导入 project.json 或预测数据包 →

2. 断点二：Step 2 自由度与“改参即作废”缺乏即时预期

用户不知关联加热器与固定积分控制已被锁定，或在修改 K/m 范围后困惑为何下载按钮失效。

布局修正：在两独立输入旁并列只读胶囊标签展示关联/固定项；参数变更时将计划状态切换为 Needs regeneration。

微文案：

只读标签：Coupled & fixed (excluded from grid): Linked heater temp · Fixed integration controls / 已关联与固定项（不作为独立扫描维度）：关联加热器温度 · 固定积分控制

预览与防呆：Preview grid (Native units: K, m · Max 100 points · Editing inputs invalidates current plan) / 预览网格（原生单位：K, m · 上限 100 点 · 修改参数将立即作废原计划）

模式与下载：Scan mode: Verification only | Fixed train + holdout / 扫描模式：仅复核点 | 固定训练 + 留出集 -> 按钮：Confirm & download plan (.json) / 确认并下载扫描计划 (.json)

3. 断点三：Step 3 误以为网页在后台跑 Aspen，或漏掉“预测需额外打包”

用户下载计划后在网页干等，或不知如何开启预测视图。

布局修正：顶部放置单行离线提示；下方分左右两栏分别接收常规 project.json 与进阶预测 bundle。

微文案：

离线运行说明：Run serially on your local machine using an isolated Aspen copy. Failed points and file hashes are retained. / 请在本地使用隔离副本串行运行 CLI。所有求解失败点与源文件哈希均会保留。

导入区 A（常规）：Import combined project.json → Open energy, LCA & fuzzy workspace / 导入合并后的 project.json → 进入能耗、LCA 与模糊比较工作区

导入区 B（预测）：Import trained bundle (requires train + holdout check) → View sample coverage & prediction vs. simulation / 导入训练数据包（需含训练集与留出校验）→ 查看样本覆盖率及预测与仿真对比

4. 断点四：五类检查易被误读为“真机防伪认证（Verified）”

布局修正：用并排 5 个黑白状态标签替代笼统的“Verified”徽章，底部附免责微文案。

微文案：

标题：Run & data checks (from imported file records; browser cannot authenticate live Aspen execution) / 运行与数据检查（基于导入文件记录解析，浏览器端不认证真实 Aspen 运行过程）

五项标签：Control readback 控制回读 · Native solver status 原生求解状态 · Accounting balance 账面数值闭合 · LCA factor coverage LCA 因子覆盖 · Metric completeness 指标完整性。
