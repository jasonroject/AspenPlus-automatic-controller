# 冻结 17 点 HTL 代理模型：只读误差诊断

本诊断读取已冻结的原生记录、模型参数和校验输出；没有试验新核、改变超参数、调整分组、重新拟合或改动 5% 标准。模型仍为 `exploratory`，普通预测未启用。

**结论：5% 失败集中在 335 ℃ / 8.5 m；345 ℃ / 17.5 m 的三项响应均通过。** 当前证据未发现单位换算、指标映射或保存后均值重建错误。较差点位于训练凸包内，但处在长度采样较疏、局部四角缺少一个训练点的区域。现有数据支持“当前稀疏训练设计未捕捉该处响应形状”的解释方向，不能证明唯一成因，也不能推导具体化学或流动机制。

335 ℃ / 8.5 m 的产率差为 −0.0059962247 fraction，即 **−0.599622 个百分点**；不能把 −9.77% 的相对误差写成 −9.77 个百分点。345 ℃ / 17.5 m 为 +0.074022 个百分点。

3 个 holdout 的组内最大绝对相对误差分别为能耗 1.444251%、目标/feed 0.730767%、气候影响 1.334451%。这些 holdout 均位于原始矩形网格的温度/长度水平上；两条 verification 额外检验了网格水平之间的位置。3 个 holdout 通过不覆盖全部网格间响应。

## 换算与实现问题的排查范围

独立审计脚本已核查下列链条，当前均一致：

- 原生控制以 K 输入，335 ℃→608.15 K、345 ℃→618.15 K；长度仍为原生 `meter`。独立变量、加热器恒等温度链接和固定积分控制的运行前后回读均匹配计划。
- 原生质量为 kg/h；比焓由 cal/g 以声明的 `4.1868 J/cal` 换算，焓流为 `mass_kg_h × h_cal_g × 4.1868 / 3600` kW。热/功 cal/s→kW 的系数为 `4.1868/1000`。逐块与边界有符号残差重新求和通过。
- 产品分母是两终端物流中的 catechol + o-cresol 目标出口质量合计，**不是分离回收率**。目标/feed 以 fraction 保存，仅显示百分数时乘 100；两项单位产品指标使用相同目标质量分母。
- 能耗是继承的 heater + reactor + fixed-pump 受限购能清单，气候指标使用冻结前景映射和原因子；排除 separator heat 与 cooling-service burdens。不能把它们改称全厂净购能或完整全厂 LCA。
- 原生 readout 的 path、unit、源 archive/profile hash、报告和副本文件 hash 匹配；固定 LCIA 因子/分配值/流程连接匹配 profile。17 点五项门禁通过，逐块最大质量残差约 `5.88e-4 kg/h`、最大能量残差约 `2.17705e-6 kW`。
- 标准库独立重建 Matérn 均值，并核对训练-only 输入/输出缩放与保存系数的 `C·alpha = y_normalized` 方程；训练 ID 仅原 12 行，3 holdout 和2 verification 未进入训练。5 个校验值和误差、81 个情景均值/排名算术均一致。

这些检查排除了已检查范围内的单位错配、fraction/% 混淆、分母误接和纯 JSON 均值重建错误；它们不证明物性/动力学模型正确，也不能排除原生模拟对积分、求解路径或未声明物理条件的敏感性。原生 warnings 保留，不能用极小闭合残差代替物理验证。

一个纯代数诊断也值得保留：在失败点，将能耗或气候预测乘以预测目标/feed，并与相同原生乘积比较，偏差分别为 −4.572835% 和 −1.166837%。原生这些乘积为 0.148974666 kWh/kg-feed 和 0.630168021 kg CO₂-eq/kg-feed；预测乘积为 0.142162300 和 0.622814984。它说明单位产品指标对目标质量分母敏感，低估目标/feed 与高估单位产品气候影响方向相容。三个响应目前由独立 GP 拟合，**这些乘积不是新原生清单、守恒证明或原因分解**，也不能拿较小乘积误差替代原 5% 单位产品指标检验。

## 下一轮的独立设计建议（本次未执行）

1. 先保留原模型和所有失败结论。若核查 335 ℃ / 8.5 m 的原生执行一致性，可另设同坐标重复运行，明确它是重复性检查而非新的独立位置；不以重跑替换这次 verification。若重复差异明显，先查原生数值行为，再谈代理模型密度。
2. 为解析已发现区域，可以另立有标识的**自适应诊断阶段**，固定检查 T=332.5/337.5 ℃ × L=7/9.5 m 四点，并在335 ℃增加 L=7/10 m 两点；连同中心重复，覆盖温度与长度两个方向。这些点因看到本次失败而选择，不能再声称是无条件独立验证。它们不在本次报告中执行，也不自动进入原训练集。
3. 若之后明确开发第二版模型，必须在生成第二版响应前冻结训练、开发校验和最终验证坐标/用途。可增加长度层级，例如 5/7.5/10/12.5/16.25/20 m，并在全域配置不与训练重合的交错验证位置；具体点数与分配须按预算和实际模型适用域另行制定。需要同时覆盖失败邻域与其他区域，不能仅选当前表现好的局部9点。
4. 原两条 verification 已被用于诊断，后续属于开发证据；新模型不得把重新使用它们得到的低误差称为全新的独立验证。需要新保留点、相同单位明确的预注册误差政策以及全部失败保留。新模型应独立版本化，旧 `exploratory` 工件仍可追溯。
5. 正在执行的 330 ℃ / 12.5 m 周围9点属于另一事先冻结的局部核验，包含8个新坐标和1个原holdout重复。它不覆盖335 ℃ / 8.5 m的失败邻域，不能靠该局部通过来解除本模型的全局误差门禁，也不能验证9候选的全局名次稳定性。
