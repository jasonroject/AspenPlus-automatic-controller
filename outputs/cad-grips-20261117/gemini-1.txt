一、最容易出现的状态冲突与语义调整建议共享点与选中直线的“冷夹点重叠”与单击激活仲裁冲突点：用户选中一条直线后，其端点蓝夹点与底层共享 POINT 位置重合。点击该处 < 3px 松开时，是激活直线的端点 Stretch 热夹点，还是先选中了 POINT 再激活 POINT 的热夹点？按既有强联动约定，二者 Stretch 结果一致（均联动相连线），但若选中了多条线，点中夹点究竟触发“单端点 Stretch”还是“多选集体 Move/Rotate”必须明确。必须调整的语义：点击某条已选直线的端点蓝夹点激活热夹点时，Stretch 模式仅移动该激活端点（及相连线），但一旦用户按空 Enter/Space 切换到 Move / Rotate / Scale / Mirror 模式，变换目标必须自动扩大为当前所有已选中的图元集合（以该热夹点为基点），这样才完全符合 AutoCAD 夹点编辑直觉。空 Enter/Space 的三级消费优先级（热夹点 > 绘制中 > 重复命令）冲突点：同时存在“热夹点模式切换（空输入）”、“LINE 指定起点时的空回车续画”、“空闲状态的空回车重复命令”，三者均抢占 Enter/Space。此外，输入缓冲为空时直接按 Enter/Space 切换模式，但若用户输入了空格字符本身（如误敲空格），不能当成非空坐标解析报错。必须调整的语义：严格按状态机顶层互斥路由按键：1. 热夹点激活态（缓冲为空 -> 循环 5 模式；缓冲非空 -> 解析数值提交并退出热夹点） > 2. 命令活跃态（LINE 待起点且缓冲为空 -> 触发续画；LINE 待下一点且缓冲为空 -> 结束命令） > 3. 空闲态（缓冲为空 -> 重复上一条绘图命令）。热夹点预览态下的“保存 / 导出 / 切换视图 / Undo”脏读风险冲突点：热夹点激活后处于“悬空预览态”（已写入预览变换但尚未点击或回车提交）。此时用户若直接按 Ctrl+S 保存、点击顶部“导出”、切换模型/草图视图或按 Ctrl+Z，极易把未确认的预览态序列化进工程，或因 Ctrl+Z 回退了上一条已提交历史而导致当前预览基准点丢失报错。必须调整的语义：热夹点预览态视作未提交的模态事务（Pending Transaction）——触发保存、导出、切换工具或切换视图前，自动执行等价于 Esc 的取消预览回滚（仅保留原几何）；热夹点激活期间按 Ctrl+Z 应优先等价于 Esc 取消当前热夹点编辑，而非直接穿透去撤销更早的历史记录。草图 LINE 末端续画（空回车）后的拓扑复用与 Undo/Delete 追踪冲突点：用户画完线段 P1−P2P_1-P_2P1​−P2​ 后，若紧接着按 Ctrl+Z 撤销了 P1−P2P_1-P_2P1​−P2​，或者在模型浏览器中删除了 P2P_2P2​，此时内存里缓存的 lastLineEndPointId 变成了悬空失效 ID（Dangling ID）。此时再执行 LINE + 空回车续画，若不校验存活状态会直接报错或连向已删除坐标；另外，如果上一条 LINE 是“独立不共点”模式绘制的，续画时应复用其末端坐标/点实体以保持连续性。必须调整的语义：不单独维护易过期的静态变量，而是在每次命令提交、Undo、Redo、Delete 后动态解析“当前草图中最后创建且仍存活的草图 LINE 终点（lastValidLineEndPoint）”。若不存在存活的草图直线，空回车续画静默忽略或提示“无可续画的草图直线”。Mirror（镜像）与锁定图元、共享拓扑的冲突冲突点：Move / Rotate / Scale 都是保拓扑变换，直接修改选中点坐标即可；但 Mirror（镜像）在 AutoCAD 夹点编辑中默认是直接翻转原图元（不保留原件，除非按 Ctrl 复制）。若选中一条与未选中线段共点的直线进行 Mirror，直接翻转其端点坐标会把未选中的相邻直线一起拉扯变形，产生极怪异的几何扭曲。必须调整的语义：锁定检查前置：点击蓝夹点激活热夹点前，若激活点或任意受影响图元包含已锁定构件，直接拦截激活并在画布浮标提示锁定原因，不进入虚线预览态。拓扑提示：单选共点直线执行 Mirror 时，淡蓝虚线同步预览受拉扯的邻边（与 Stretch 保持一致的所见即所得），避免用户误以为是克隆镜像。斜线中点默认 Move 时的捕捉基点与方向参考冲突点：线中点点击激活热夹点默认进入 Move，以中点为基点。此时若使用鼠标移动或输入 @dx,dy / 方向+距离，逻辑清晰；但按空 Enter 切到 Rotate 或 Mirror 时，文档规定“角度从世界 +X 轴计算”，需在画布上同步画出过热夹点基点的水平 +X 参考虚线及当前角度扇形/弧线，否则用户对着斜线按中点旋转时无法直观判断 0° 基准方向。二、8 个关键验收测试用例编号测试场景初始状态与操作步骤预期正确结果（验收标准）T1单击激活热夹点 vs 按住拖拽分流选中一条直线 AB（显示两端及中点共 3 个蓝夹点）。1. 在 B 端蓝夹点按下并 < 3px 松开。2. 移动鼠标观察预览，按 Esc。3. 再次在 B 端蓝夹点按下不松，直接拖动 30px 后松开。1. 松开瞬间 B 夹点变为红色热夹点，状态栏提示 Stretch，移动鼠标出现虚线预览，实际几何未改。2. Esc 退出热夹点，恢复蓝色冷夹点，直线仍保持选中状态。3. 直接按住拖动超过 3px 仍走原直接拖拽逻辑，松手即提交一次原子历史。T2五模式空回车循环与基点继承选中一条水平线 AB，点击中点蓝夹点激活（默认 Move），连续按 5 次空 Enter（或 Space）。模式严格按 Move → Rotate → Scale → Mirror → Stretch → Move 循环切换；整个循环过程中基点始终锁定在该中点，虚线预览随模式实时切换。T3多选切换模式的变换范围扩张同时选中两条平行线 L1​,L2​，点击 L1​ 端点蓝夹点激活（默认 Stretch）。1. 移动鼠标观察 Stretch 预览。2. 按 1 次空 Enter 切换到 Move 并输入 @0,20 回车提交。1. Stretch 阶段仅拉动 L1​ 该端点，L2​ 静止预览。2. 切到 Move 并提交后，L1​ 与 L2​ 共同向上平移 20mm，并合并为 1 条原子 Undo 记录。T4Rotate / Scale / Mirror 数值与鼠标提交精度选中线 AB，激活 A 端热夹点。1. 切至 Rotate，输入 45 回车。2. 切至 Scale，输入 2 回车。3. 切至 Mirror，输入 90 回车。1. 绕 A 逆时针旋转 45∘（世界 +X 基准）。2. 以 A 为中心放大 2 倍。3. 以过 A 的 90∘（垂直线）为轴镜像翻转，所有操作均支持单步 Ctrl+Z 完整回退。T5空回车续画及 Undo/Delete 后的安全降级用 L 绘制折线 P1​−P2​−P3​ 并 Enter 结束。1. 立刻按 Enter 重复 LINE，在“指定起点”提示下再按一次空 Enter，点击 P4​ 完成线段。2. 按 Ctrl+Z 撤销 P3​−P4​，再重复 LINE + 空 Enter。1. 第二次空 Enter 自动以 P3​（复用共享节点 P3​）为起点拉出橡皮筋，完成后 P2​−P3​−P4​ 拓扑连通。2. 撤销后，lastValidLineEndPoint 自动回退为 P3​，空 Enter 仍能准确从 P3​ 续画；若把所有线都删光再空 Enter，不报错且停留在“指定起点”。T6热夹点预览态下的保存/导出/Undo 保护激活热夹点并移动鼠标产生明显的位移虚线预览（未点击提交）。1. 按 Ctrl+Z。2. 重新激活热夹点产生预览，直接点击顶部“保存”或“导出”。1. Ctrl+Z 仅取消当前热夹点预览（等价于 Esc），不会误删上一条已提交图形。2. 保存/导出前自动取消未提交的悬空预览，导出文件与工程数据均为原始合法坐标，无脏数据。T7锁定图元拦截热夹点激活折线 P1​−P2​−P3​ 中，锁定边 P2​P3​。选中边 P1​P2​，尝试点击 P2​ 端蓝夹点激活热夹点。拒绝进入红色热夹点预览态，保持冷夹点并在画布光标旁直接提示“关联图元已锁定”，防止进入预览后才无法提交。T8热夹点与 F3 / F8 / Shift 联动激活热夹点进入 Move 或 Stretch 预览，开启 F8 正交。1. 移动光标至斜向，按住 Shift 不动鼠标。2. 移近另一固定点 T(50.3,25.4) 并点击提交。1. 按住 Shift 瞬间虚线预览实时解除正交限制，松开立即恢复正交。2. 靠近 T 时 F3 优先吸附，点击提交后坐标精确为 (50.3, 25.4) 且保持热夹点自动退出。
