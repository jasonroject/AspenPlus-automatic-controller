# ExtrudeCAD Studio

支持中文/English 的轻量 CAD 网页工作台，由原 `F:\CAD-code\cubesketch-3d` 项目整理改进。

## 直接使用

用 Ego lite 打开 `deliverables/ExtrudeCAD_Studio.html`。脚本、样式和三维引擎全部内嵌，无需联网、安装 Node.js 或配置 API key。浏览器需支持 WebGL。

支持二维草图、Z 方向拉伸、双视图、尺寸修改、几何吸附、截面布尔、镜像/阵列、撤销重做，以及工程 JSON、SVG、DXF、OBJ、STL 和工程视图导出。

本轮补充按尺寸创建长方体/圆柱、XYZ 精确平移与复制、绕公共或自定义中心旋转/等比缩放、XY 两点测量、适合视图、构件搜索/锁定/隔离、命令搜索，以及基础 DXF 轮廓导入。功能与验证详见 `deliverables/CAD_功能优化与验证_20261117.md`。

工程自动保存到当前浏览器。不同文件路径、浏览器、隐私模式或站点地址的自动存档不保证互通；请使用「保存」下载 `.extrudecad.json` 文件，再用「打开」继续编辑。离线版本只处理本地数据，没有 AI API 调用。

新版默认采用近黑画布与深黑面板、银灰模型和蓝色选中状态。以三维主画布启动，可在顶栏切换草图、模型和双视图。左侧管理构件，右侧直接调整名称、尺寸、位置和外观；底部工具坞提供绘图、布尔与阵列，复杂选项按需展开。工程图输出保留浅色纸面。

二维、三维画布与构件树统一支持 Ctrl + 单击切换多选、Shift + 单击减选。二维单击空白处取消选择，按住拖动才框选：左→右白色实线完全包含选，右→左白色虚线交叉选；普通框选替换选择，Ctrl 框选追加，Shift 框选减选。拖框时 Esc / 右键取消本次框选并保留原选择，空闲时 Esc 清空选择。布尔预览会切到二维轮廓视图，确认后才应用；修改源对象后需要重新预览。底部数值框支持清空重输，按 Enter 或离开输入框提交。刷新或离开页面时会立即保存最新工程。

「载入结构示例」提供六构件法兰支座外形：112 × 84 × 8 mm 圆角底板、Ø48/Ø28 × 32 mm 套筒和四个六角帽。底板与套筒具有真实贯通孔。各构件独立摆放，不包含装配约束、螺纹或螺栓安装孔，不是制造图。载入示例可以撤销；已有自动存档不会被新版默认示例覆盖。

## 显示细节

顶栏「选项」设置固定侧栏尺寸：紧凑（190/230 px）、标准（220/260 px）或宽敞（260/300 px），刷新后保留。每个视图上方用 − / ＋、百分比、100% 和「适合」控制缩放，面板和按钮保持原尺寸。编辑画布内滚轮以鼠标位置为中心缩放图形，面板外观保持固定；Ctrl+滚轮也不会缩放整个页面，列表仍可滚动。倍率范围为 0.01%–100000%，不是打印比例。最新行为与验证见 `QA.md` 顶部。

二维草图左上「显示」可调整点样式、点尺寸、线显示宽度和节点/点名可见性。默认隐藏连线节点的常驻符号，靠近鼠标时显现；选中夹点为蓝色，捕捉标记为绿色。屏幕显示设置不改变几何或导出线宽。详情见 deliverables/CAD_点线显示与黑色主题_20261117.md。

## 点线一体

底部「点线」或 L↵：首击落点，后续连续连线，已有点自动复用。移动点联动相连直线，拖动端点会同步更新共用点。U↵撤一步，C↵闭合，Esc结束。关联关系随工程保存；DXF仅交换几何。详情见 deliverables/CAD_点线绘制与联动_20261117.md。

点线拖动支持 F3 精确捕捉、F8 正交及 Shift 临时切换；会排除正在随动的点与线，避免吸住自身。拖线身时可用端点或中点对齐目标，整条线保持原长。画布显示联动线数和锁定原因，单次拖动可整体撤销；Esc或切走标签页会回滚。重合点不会自动合并，继续拖动优先命中已选点。与传统 CAD 的区别及本轮测试见 `deliverables/CAD_点线交互回归与传统CAD差异_20261117.md`。

结束绘图后，Enter/空格重复工具；LINE 等待起点时再按空 Enter/空格，从最近存活直线末端续画。选中点或草图直线后单击蓝夹点可激活红色夹点；空 Enter/空格切换拉伸、移动、旋转、缩放、镜像，输入数值回车或点击目标确认。Esc/Ctrl+Z 取消当前夹点并保留选择，确认后的联动编辑可一次撤销。输入中的精确预览、按钮后的键盘焦点和面板退出路径也已优化。操作与50项实测记录见 `deliverables/CAD_续画与夹点编辑验证_20261117.md`。

上一轮验证白色选框、追加/减选预览、提示遮挡和修饰键选择边线，共 57 项实测记录见 `deliverables/CAD_白色框选与草图选择验证_20261117.md`。

根据随后实际使用反馈，已取消两击框选：单击空白清空选择，按住拖动才显示选框，松手立即结束。二维和三维画布恢复滚轮缩放，画布外组件保持固定尺寸；旧报告中的“两击框选”和“画布禁用滚轮”已由本次行为取代。按住鼠标拖动编辑/框选时暂不响应滚轮，避免同一手势中坐标跳变；点击激活的夹点和连续绘图仍可缩放视图。

## 快捷键、清屏与语言

右侧属性栏标题右边可收起/展开，快捷键 `Ctrl+1`。`Ctrl+0` 进入或退出清屏编辑，保留画布、命令行和退出入口，并记住进入前的侧栏开关。`Ctrl+9` 显示/隐藏命令行。顶栏「选项」可切换中文/English，刷新保留；图纸中的对象名称不随语言改变。

空闲时输入命令别名，再按回车或空格执行：`L` 点线、`REC` 矩形、`C` 圆、`PO` 点、`M` 移动、`CO` 复制、`RO` 旋转、`SC` 缩放、`E` 删除、`DI` 测距、`Z` 适合视图。`F1` 查看应用内帮助；`F3/F7/F8/F9` 分别控制捕捉、网格显示、正交和网格吸附。M 不再是测量快捷键。完整用法、与 AutoCAD 的差异和本轮 60 项 Ego 检查见 [验证记录](deliverables/CAD_快捷键清屏与双语验证_20261117.md)。

## 精确建模与文件交换

- 「添加」中输入中心、底面标高、宽/深或直径及高度；再次打开会保留本次会话最近创建参数。
- 「变换」支持相对 XYZ 位移、XY 旋转、XYZ 等比缩放及复制。多选默认围绕组合包围盒中心，也可输入自定义中心；锁定或隐藏对象不参与变换。
- 输入 `DI` 后回车进入 XY 测量，连续点两次读取距离、ΔX、ΔY 与角度。测量不写入模型。输入 `Z` 后回车找回全部可见构件。
- 按 `Ctrl+K` 搜索命令；`V/L/REC/C/PL/DI` 后回车分别为选择、点线一体、矩形、圆、多边形、测量；`M/RO/SC` 后回车打开移动/旋转/缩放面板；`Ctrl+S/Z/Y/D/A` 分别保存、撤销、重做、复制、全选。
- 「打开 → 导入图元 .dxf」追加轮廓，可一次撤销。支持 ASCII DXF 模型空间的 POINT、同标高 LINE、闭合直线 LWPOLYLINE 与 CIRCLE；圆按 72 段近似。自动识别 mm/cm/m/in/ft 并转换为毫米，未声明单位时要求手动选择。
- 导入前会说明不支持或无效的实体。纸空间、显式隐藏实体、关闭/冻结图层不导入；不展开 BLOCK/INSERT，不支持 bulge、非零线宽或非 +Z OCS。部分导入按钮显示将跳过和导入的数量。
- DXF 导出为毫米 AC1015 的 POINT、LINE 和闭合 LWPOLYLINE，保留轮廓、标高及厚度。自家导出的单孔标记可恢复内孔；外部嵌套轮廓各自独立。材质、倒角、锁定及编辑历史仍使用工程 JSON 保存。

## 模型范围

这是 XY 草图沿 Z 方向拉伸的轻量编辑器。尺寸单位为 mm；STL 本身不记录单位，导入其他软件时请选择 mm。圆形轮廓和曲面使用多边形近似。界面体积基于拉伸截面估算，倒角会使实际网格体积略有差异。

布尔运算针对 A/B 的 XY 截面及其内孔，保持原坐标，结果沿用 A 的高度和标高。B 的 Z 位置不参与截面切割。当前单构件仅表示一个外轮廓与至多一个内孔；空集、多块、多孔及孔与外环相切的结果会明确停止应用。尚不具备约束求解、特征历史树、任意空间实体布尔、装配约束或 DWG/STEP 导入。
